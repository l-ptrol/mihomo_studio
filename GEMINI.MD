# Инструкции для Mihomo Studio (Go)

Этот файл содержит правила работы с проектом для AI-ассистента (Gemini). Соблюдайте их неукоснительно.

## 1. Версионирование
Перед каждым пушем изменений, которые затрагивают функционал или UI, необходимо повышать минорную версию на уровне патча (третье число: X.Y.Z -> X.Y.Z+1).

**Файлы для обновления версии:**
1.  `build.sh`: Переменная `VERSION`.
2.  `cmd/server/main.go`: Переменная `Version`.
3.  `install.sh`: Заголовок в начале файла и сообщение в блоке `echo`.
4.  `web/templates/index.html`: Тег `<title>` и блок `.brand-version`.

## 2. Сборка (Build)
Если пользователь одобрил сборку, необходимо скомпилировать бинарники под все целевые архитектуры:
- **MIPS (Big Endian)**: `GOOS=linux GOARCH=mips go build -ldflags="-s -w -X main.Version=$VERSION" -o dist/mhstudio-mips ./cmd/server`
- **MIPSEL (Little Endian)**: `GOOS=linux GOARCH=mipsle go build -ldflags="-s -w -X main.Version=$VERSION" -o dist/mhstudio-mipsel ./cmd/server`
- **ARM64 (AARCH64)**: `GOOS=linux GOARCH=arm64 go build -ldflags="-s -w -X main.Version=$VERSION" -o dist/mhstudio-aarch64 ./cmd/server`

## 3. Коммит и Пуш (Commit & Push)
- Всегда пушить в ветку `test-go`.
- Коммиты должны быть описательными (на русском языке).
- После завершения любой задачи ВСЕГДА спрашивать: **«Выполнить сборку, коммит и пуш?»**. Переходить к действиям только после одобрения.

## 4. UI Правила
- Стиль: Милинистичный, Premium.
- Иконки: Только **SVG Outline**. Никаких эмодзи в интерфейсе.
- Кнопки: Однородные классы `.btn`, прозрачные/ghost стили для второстепенных действий.
- Мультиязычность: Все новые функции, диалоги и прочие элементы, содержащие текст, должны быть переведены на русский, английский и украинский языки. Используй i18n для перевода интерфейса.
